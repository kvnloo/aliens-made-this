# Pizza Food App - Style Guide

## Design Analysis
Multi-screen food delivery app UI with warm, peachy color scheme. Features pizza and bakery items with a clean, modern aesthetic.

## Color Palette
- **Primary Background**: `#FFECD9` (Warm peach/cream)
- **Secondary Background**: `#4A3728` (Dark brown)
- **Accent Orange**: `#FF9B5E` (Bright orange for CTAs)
- **Text Primary**: `#2D2419` (Dark brown/black)
- **Text Secondary**: `#8B7355` (Medium brown)
- **White**: `#FFFFFF`
- **Light Cream**: `#FFF5E6`

## Typography
- **Primary Font**: Inter, system-ui, sans-serif
- **Headings**: 24-32px, Bold (700)
- **Subheadings**: 16-20px, Semibold (600)
- **Body Text**: 14-16px, Regular (400)
- **Captions**: 12-14px, Regular (400)

## Spacing System
- **Container Padding**: 20-24px
- **Card Spacing**: 16px gap
- **Element Spacing**: 8-12px
- **Border Radius**: 16-24px (soft, rounded)

## Component Styles

### Cards
- Background: White or light cream
- Border radius: 16-20px
- Padding: 16-20px
- Shadow: subtle, soft shadow

### Buttons
- **Primary**: Orange (#FF9B5E), rounded-full, white text
- **Secondary**: Outlined, dark text
- **Icon Buttons**: Circular, minimal

### Images
- Food images: Rounded corners (12-16px)
- High quality, centered
- Aspect ratio: varies by context

## Layout Patterns
- Mobile-first design (375px width)
- Vertical scrolling
- Card-based layouts
- Grid systems for product displays
- Bottom navigation or CTAs

## UI Elements
- Rating stars: Yellow/orange
- Price tags: Prominent, bold
- Quantity selectors: Minimalist +/- buttons
- Category filters: Pill-shaped buttons
- Search bars: Rounded, with icons
