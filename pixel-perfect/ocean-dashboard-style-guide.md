# Ocean/Whale Dashboard - Style Guide

## Design Analysis
This is a futuristic ocean-themed dashboard with a whale visualization and scientific data displays.

### Color Palette
- **Primary Background**: Dark navy/teal (#0a1929, #152238)
- **Accent Cyan/Teal**: #00e5ff, #1de9b6, #00bcd4
- **Text Colors**:
  - Primary: #ffffff
  - Secondary: rgba(255, 255, 255, 0.8)
  - Muted: rgba(0, 229, 255, 0.6)
- **Chart Colors**: Cyan gradients with glow effects

### Typography
- **Primary Font**: 'Rajdhani', 'Orbitron', sans-serif (futuristic)
- **Headings**: 700 weight, uppercase letter-spacing
- **Body**: 400-500 weight
- **Numbers**: 700 weight, monospace feel
- **Title**: HOLIHACUIND (custom display font style)

### Main Components

1. **Hero Section** (Whale visualization)
   - Large whale silhouette with particle effects
   - Glowing cyan edges
   - Underwater gradient background
   - Floating data points

2. **Top Stats Bar**
   - Circular progress indicators
   - Large percentage displays
   - Small descriptive text below
   - Glow effects on active elements

3. **Radial Navigation** (Top left)
   - Circular menu layout
   - Connected nodes
   - Cyan connection lines
   - Hover glow states

4. **Bottom Stats Grid**
   - Horizontal progress bars with dual colors
   - Percentage labels
   - Small descriptive text

5. **Circular Gauges** (Bottom center)
   - Ring progress indicators
   - Large percentage text
   - Small labels below
   - Cyan glow effect

6. **Bar Chart** (Bottom right)
   - Vertical bars with cyan gradient
   - Area chart overlay
   - Grid lines
   - Axis labels

### Effects
- **Glow**: box-shadow: 0 0 20px rgba(0, 229, 255, 0.5)
- **Particle effects**: Small cyan dots with opacity variation
- **Scan lines**: Subtle horizontal lines for tech feel
- **Blur backdrop**: backdrop-filter: blur(8px)

### Spacing
- Container padding: 2rem
- Card gaps: 1.5rem
- Section margins: 3rem
- Small gaps: 0.75rem

### Border Radius
- Cards: 0.75rem (12px)
- Circular elements: 50%
- Small elements: 0.5rem (8px)

### Animations
- Pulse effect on metrics
- Glow intensity variation
- Particle floating animation
- Progress bar fills

### Chart Styles
- Cyan (#00e5ff) primary color
- Gradient fills: linear-gradient(180deg, rgba(0,229,255,0.3), transparent)
- Glow on data points
- Smooth curves on line charts
