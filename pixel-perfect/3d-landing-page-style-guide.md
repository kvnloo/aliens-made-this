# 3D Landing Page - Style Guide

## Design Analysis
Vibrant, playful landing page with bold 3D illustrations and a warm orange gradient background. Features French text "ORAR YOIN'TOUI OUQUITAL'STOO" as hero headline.

## Color Palette
```css
--primary-orange: #ff9500
--secondary-yellow: #ffd000
--accent-red: #ff5757
--accent-pink: #ff6b9d
--accent-purple: #9b59b6
--accent-cyan: #00d4ff
--white: #ffffff
--text-dark: #2c3e50
--gradient-warm: linear-gradient(135deg, #ff9500 0%, #ff6b00 100%)
--gradient-sunset: linear-gradient(180deg, #ffd000 0%, #ff9500 100%)
```

## Typography
- **Heading Font**: 'Poppins', sans-serif (Extra Bold - 800)
- **Body Font**: 'Inter', sans-serif
- **Accent Font**: 'Space Grotesk', sans-serif

### Font Sizes
- Hero Title: 64px / 4rem (Bold, uppercase)
- Section Title: 36px / 2.25rem
- Card Title: 20px / 1.25rem
- Body: 16px / 1rem
- Caption: 14px / 0.875rem

## Layout Structure
- Desktop: Max-width 1200px
- Hero: Full-width with centered content
- Cards Section: White background with 3-column grid
- Spacing: 8px base (multiples of 8)
- Border Radius: 24px for cards, 12px for buttons

## 3D Illustration Style
### Main Hero Scene
- Large central volcano/mountain structure
- Colorful geometric buildings and structures
- Floating spheres and abstract shapes
- Characters/figures for scale
- Layered depth with foreground/background elements

### Color Treatment
- Warm orange/yellow primary palette
- Rainbow accent colors (pink, purple, cyan, red)
- High saturation, vibrant tones
- Soft shadows for depth

## Components

### Hero Section
- Full-width orange gradient background
- Large 3D illustration centerpiece
- White bold uppercase headline
- Minimal text, maximum visual impact

### Feature Cards
- White background section
- Three-column layout
- 3D icon illustrations (sphere, lightbulb, building)
- Orange CTA buttons
- Ample white space

### Buttons
- Primary: Orange (#ff9500) with rounded corners
- Hover: Darker orange (#ff6b00)
- Padding: 14px 32px
- Border radius: 24px (pill shape)

## Visual Effects
- Soft drop shadows: 0 4px 24px rgba(0, 0, 0, 0.08)
- 3D illustrations have layered shadows
- Hover animations: scale(1.05) on cards
- Smooth transitions: 0.3s ease

## Content Structure
- Hero: Large visual + minimal text
- Features: "Rendons créative" section with 3 cards
- Each card: Icon + Title + Description + CTA
- Centered, symmetrical layout

## Accessibility
- High contrast text on backgrounds
- Large, readable fonts
- Clear visual hierarchy
- Descriptive alt text for 3D illustrations
