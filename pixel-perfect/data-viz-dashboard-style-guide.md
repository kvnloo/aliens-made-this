# Data Visualization Dashboard - Style Guide

## Design Analysis
This is a sophisticated data visualization dashboard with a nature-inspired theme featuring mountain landscapes.

### Color Palette
- **Primary Background**: Dark slate/charcoal (#2d2a3e, #3a3649)
- **Card Backgrounds**: Semi-transparent dark with blur effect (rgba(45, 42, 62, 0.8))
- **Accent Colors**:
  - Orange/Coral: #ff8a65, #f4a261
  - Teal/Cyan: #4dd0e1, #26c6da
  - Purple: #7e57c2
  - Pink: #ec407a
- **Text Colors**:
  - Primary: #ffffff
  - Secondary: rgba(255, 255, 255, 0.7)
  - Muted: rgba(255, 255, 255, 0.5)

### Typography
- **Primary Font**: 'Inter', sans-serif
- **Headings**: 600-700 weight
- **Body**: 400-500 weight
- **Numbers**: 700 weight, tabular-nums
- **Small Text**: 300 weight, 0.75rem

### Card Components
1. **Stats Cards** (Top right)
   - Small circular icons
   - Large metric numbers
   - Percentage changes with arrows
   - Blur backdrop effect

2. **Chart Cards** (Middle)
   - Dark semi-transparent backgrounds
   - Rounded corners (1rem)
   - Padding: 1.5rem
   - Box shadow with slight blur

3. **Donut Chart Card** (Bottom left)
   - Multi-color donut chart
   - Legend with colored dots
   - Data table below chart

4. **Planet/Space Card** (Bottom middle)
   - Image-based design
   - Overlay text
   - List items with icons

5. **Landscape Card** (Bottom right)
   - Full background image
   - Overlay metrics
   - Gradient overlay

### Spacing
- Card gaps: 1rem
- Internal padding: 1.5rem
- Section margins: 2rem
- Icon spacing: 0.5rem

### Border Radius
- Cards: 1rem (16px)
- Buttons: 0.5rem (8px)
- Small elements: 0.375rem (6px)

### Shadows
- Card shadow: 0 8px 32px rgba(0, 0, 0, 0.3)
- Hover shadow: 0 12px 48px rgba(0, 0, 0, 0.4)

### Charts
- **Donut Chart**: Multi-segment with orange, purple, teal colors
- **Line Charts**: Area fills with gradients
- **Bar Charts**: Coral/orange gradient fills

### Glassmorphism Effect
- backdrop-filter: blur(10px)
- background: rgba(45, 42, 62, 0.8)
- border: 1px solid rgba(255, 255, 255, 0.1)
