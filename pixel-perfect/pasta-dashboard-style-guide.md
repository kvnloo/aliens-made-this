# Pasta Dashboard - Style Guide

## Design Analysis
Sophisticated food nutrition/recipe dashboard with a premium, clean aesthetic. Features beautiful food photography and detailed nutritional information.

## Color Palette
- **Background**: `#F5F3ED` (Warm off-white)
- **Sidebar**: `#F9F5E8` (Light cream)
- **Cards**: `#FFFFFF` (Pure white)
- **Accent Mint**: `#9BC4A8` (Soft mint green)
- **Accent Gold**: `#D4A574` (Warm gold/tan)
- **Accent Rust**: `#C87850` (Warm rust/terracotta)
- **Text Primary**: `#2B2520` (Deep brown/black)
- **Text Secondary**: `#8B7E74` (Medium gray-brown)
- **Border**: `#E8E4DC` (Light beige)

## Typography
- **Primary Font**: 'Poppins', sans-serif (or similar elegant sans)
- **Display**: 32-48px, Bold (700)
- **Headings**: 20-28px, Semibold (600)
- **Body**: 14-16px, Regular (400)
- **Captions**: 12-14px, Light (300)

## Spacing System
- **Container Padding**: 32-48px
- **Card Padding**: 24-32px
- **Grid Gap**: 24-32px
- **Element Spacing**: 16-24px
- **Border Radius**: 24-32px (generous, modern)

## Component Styles

### Cards
- Background: White with subtle shadow
- Border radius: 24-28px
- Padding: 24-32px
- Shadow: `0 4px 20px rgba(0,0,0,0.08)`
- Border: Optional 1px solid #E8E4DC

### Sidebar Navigation
- Background: Cream (#F9F5E8)
- Rounded corners: 32px
- Icons: Outlined, minimalist
- Active state: Highlighted background

### Nutrition Metrics
- Large numbers: 48-64px, Bold
- Units: 16-20px, Light
- Color-coded by category
- Circular or rounded rectangular containers

### Progress Bars
- Height: 6-8px
- Rounded ends: Full rounding
- Color-coded by ingredient/nutrient
- Background: Light gray (#E8E4DC)

### Food Images
- High-quality, realistic photography
- Rounded corners: 20-24px
- Floating effect with shadows
- Natural lighting emphasis

## Layout Patterns
- Desktop-first (1200px+ width)
- Sidebar + Main content layout
- Grid-based product cards (3-4 columns)
- Asymmetric layouts for visual interest
- Generous whitespace

## UI Elements
- Tags/Pills: Outlined, rounded-full, minimal
- Calorie badges: Small, circular, color-coded
- Ingredient icons: Soft, natural colors
- Nutritional charts: Clean, minimal bar charts
- Color indicators: Red, orange, green, yellow theme

## Visual Style
- Clean and minimal
- Premium feel with generous spacing
- Soft, natural color palette
- High-quality food photography
- Subtle shadows and depth
- Rounded, friendly shapes
