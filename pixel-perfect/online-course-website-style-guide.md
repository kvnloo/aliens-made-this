# Online Course Website - Style Guide

## Design Analysis
A sophisticated online course platform with a moody, atmospheric aesthetic featuring environmental education themes.

## Color Palette
```css
--primary-dark: #1a2332
--secondary-dark: #2d3e50
--accent-orange: #ff9644
--accent-coral: #ff7b5f
--muted-sage: #7a9d88
--muted-teal: #5a7d7c
--text-light: #e8ebe9
--text-muted: #a0b0b8
--card-bg: rgba(45, 62, 80, 0.6)
--overlay-dark: rgba(26, 35, 50, 0.8)
```

## Typography
- **Heading Font**: 'Space Grotesk', sans-serif
- **Body Font**: 'Inter', sans-serif
- **Accent Font**: 'JetBrains Mono', monospace

### Font Sizes
- Hero Title: 48px / 3rem
- Section Title: 32px / 2rem
- Card Title: 24px / 1.5rem
- Body: 16px / 1rem
- Small: 14px / 0.875rem

## Layout Structure
- Desktop: Max-width 1400px, centered
- Grid: 12-column responsive grid
- Spacing: 8px base unit (8, 16, 24, 32, 48, 64)
- Border Radius: 16px standard, 24px for cards

## Components

### Hero Section
- Full-width background with atmospheric imagery
- Gradient overlay for text legibility
- Large hero illustration (isometric building/environment)
- CTA buttons with gradient backgrounds

### Course Cards
- Semi-transparent dark background
- Rounded corners (16px)
- Hover state: Lift effect with shadow
- Icon badges with orange/coral accents
- Progress indicators

### Navigation
- Sticky header with blur backdrop
- Logo + Navigation links + User avatar
- Mobile: Hamburger menu

## Visual Effects
- Backdrop blur: 12px on cards
- Box shadow: 0 8px 32px rgba(0, 0, 0, 0.3)
- Gradient overlays for depth
- Subtle animations on hover (transform: translateY(-4px))

## Illustrations
- Isometric 3D style buildings/environments
- Orange and coral accent colors
- Floating elements (birds, clouds, abstract shapes)
- Environmental theme (trees, buildings, landscape)

## Accessibility
- WCAG AA contrast ratios
- Focus states with 2px outline
- Alt text for all images
- Semantic HTML structure
