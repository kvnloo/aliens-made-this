# aliens-made-this

Playful capability test: take design inspiration → ship pixel-perfect static HTML.

**Live site:** [kvnloo.github.io/aliens-made-this](https://kvnloo.github.io/aliens-made-this/)

Interactive preview gallery (`index.html`) with live iframes + original inspo where available.

## Lineage

Inspired by **[Alien Interfaces](https://alieninterfaces.com/)** (CJ Gammon) — AI-designed UIs plus a [YouTube series](https://www.youtube.com/playlist?list=PL08jItIqOb2oMXWRZTPua0nC3oZ6Stoul).

- Site: [alieninterfaces.com](https://alieninterfaces.com/)
- Playlist: [Alien Interfaces on YouTube](https://www.youtube.com/playlist?list=PL08jItIqOb2oMXWRZTPua0nC3oZ6Stoul)
- Background: [CJ’s write-up](https://blog.cjgammon.com/alien-interfaces-ui-ux-created-with-ai/)

**Not a port of their case studies.** Same spirit: AI UI inspo → real pages. Some product-style clones, many builds from our own `inspo/` folder.
